Place the method marker after any YAML frontmatter when emitting a method file, so a skill's frontmatter stays on line 1 and is recognized. Previously the `<!-- GENERATED BY CLEW … -->` marker was prepended to every emitted file, which pushed the `---` frontmatter of skill files off the top and made it invisible to Claude Code and other harnesses. The content hash now covers the whole file (frontmatter included), and pre-hash and marker-first files migrate to the corrected form on the next `clew setup`.
