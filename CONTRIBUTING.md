# Contributing

Thank you for your interest in clew.

clew is open for **use and feedback**, but **not yet open to external code contributions**.
The project is early and its direction is still being set, so pull requests will not be reviewed or merged for now.

## What is welcome

- **Bug reports and feedback** — please open an [issue](https://github.com/ariadne-systems/clew/issues).
Feedback on running clew under agents other than Claude Code is especially useful — that integration is built to each agent's documented conventions but not yet tested by us (see the README).

## What to hold off on

- **Pull requests** — they will not be reviewed while the project is closed to contributions.
Please don't invest effort in a PR expecting it to be merged.

This will change as clew stabilizes, and this file will be updated when it does.
