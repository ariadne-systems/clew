# Security Policy

## Reporting a vulnerability

Please report security vulnerabilities **privately** — not through a public issue or pull request.

On the repository's **Security** tab, use **Report a vulnerability** (GitHub's private vulnerability reporting).
The report stays private between you and the maintainers. We will acknowledge it, and once a fix is ready, coordinate disclosure with you.

Please do not disclose a security problem publicly before it has been addressed.

## Supported versions

clew is pre-1.0 and under active development.
Security fixes land on the latest release; earlier `0.x` versions are not maintained.
